git commit -m "$(cat <<'EOF'
feat: migrate to Argon2id and finish the secrets/deploy tooling

- Four related changes that were developed together and verified
end-to-end against a real database.

- Argon2id password hashing replaces bcrypt. HashPassword and
CheckPasswordHash keep their signatures; VerifyPassword and
NeedsRehash are new. Parameters are 64 MiB / 3 iterations / 2
threads, landing at ~90-160 ms per hash, inside the OWASP envelope
for interactive login. Nine new tests.

- The makefile now loads DB_PASSWORD and TEST_DB_PASSWORD from
secrets/secrets.enc.yaml for every target that connects to Postgres.
A cached .make-secrets.env (mode 0600) holds the decrypted values
for the duration of one make invocation. The cache is removed by
make clean and is gitignored.

- scripts/seed.go calls credentials.Load() before opening the pool, so
it runs standalone without the makefile's environment.

- The diagrams target renders PlantUML sources in docs/diagrams into
docs/images/, where the other committed images live. The previous
target produced a nested docs/diagrams/docs/diagrams/ directory
because of a combination of a relative -o flag and a relative input
path. diagrams-check is the CI target that fails when the committed
SVG is stale.

-Note: The development database needed a reset: make db-reset.
EOF
)"
